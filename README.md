# 📖 About

USTHB ExoHub is an open-source Telegram platform designed for USTHB students.

The project aims to organize university exercises instead of leaving them scattered across Telegram groups and personal chats.

Students can easily browse exercises by:

- Language
- Academic Year
- Specialty
- Module

Each exercise can have multiple community-contributed solutions, making learning easier and more collaborative.

---

# ✨ Features

- 📚 Browse exercises by module
- 🔎 Search for exercises
- 📄 PDF exercise management
- 🖼️ Automatic exercise image preview
- ➕ Community solution submission
- 📂 Organized database using Supabase
- 👮 Permission system for contributors
- 🚀 Fast Telegram Bot built with Aiogram
